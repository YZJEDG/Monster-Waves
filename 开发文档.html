1构建与运行

项目内容

产物build/libs/monsterwaves-1.0.1.jar

2源码结构

根包：com.mcmod.monsterwaves（src/main/java/com/mcmod/monsterwaves/）

类职责
MonsterWavesMod@Mod 主类。必须无参构造器（1.20.1 限制）；用 FMLJavaModLoadingContext.get().getModEventBus() 注册物品（47.4.10 已 deprecated，勿改成 1.20.4+ 的构造器注入）
config/MWConfigCloth Config AutoConfig 配置类（JSON：config/monsterwaves.json5）；游戏内 Mods 列表 → Config 按钮开 GUI；服务端 MWConfig.get() 每次读取最新值（即时生效）
data/PlayerDataManager技能点：NBT 存储、AttributeModifier 应用（百分比 MULTIPLY_TOTAL）、API 事件发布、旧属性球数据一次性迁移
api/*Event（4 个）开发者钩子：SkillPointGain/Spent/ResetEvent + MobAttributeCalculateEvent（可取消/自定义值，Forge 总线）
network/NetworkHandler 等SimpleChannel：C2S 请求同步/加点/重置，S2C 数据同步/打开界面
client/SkillScreen 等FTB Library 加点界面（ButtonListBaseScreen：搜索+滚动+标题栏）、客户端缓存、按键（P）
stage/StageManager + StageData阶段列表、切换广播；SavedData 持久化（主世界 level.dat，键 monsterwaves_stage）
spawn/MobSpawnManager生成引擎：tick 调度、位置选择、生物池、难度/阶段应用、精英/Boss 升级入口
mob/EliteBossHandler + BossManager精英/Boss 升级（属性×倍率、改名发光）、Boss 血条（ServerBossEvent 紫色条）
item/ModItems + 3 符咒物品注册；休息符咒/回归符咒/战斗符咒（右键传送，永久使用无冷却）
safe/SafeDimensionManager休息维度：空岛生成（功能方块+满级附魔台）、玩家规则、跳下传送；IslandData 幂等标记
arena/ArenaDimensionManager刷怪维度：超平坦战场、传送入口、出生点、启用开关
mob/MobTeleportHandler怪物传送（防溢出）：远离玩家自动拉回
enchant/ModEnchantments + PainTransferenceHandler + GunPainTransferenceHandler苦痛传递附魔：近战/弓弩/TaCZ 触发（tacz 相关独立类，仅 tacz 加载时注册）
event/ModEventHandler服务端事件：tick（阶段+生成+拾取+规则）、登录/重生/换维度属性应用、统一掉落（三表分级）、经验加成、状态播报、指令注册
command/MonsterWavesCommand/monsterwaves 指令树（全部 Tab 补全）
资源：pack.mcmeta 必须存在（缺失则 Forge 不索引 assets）；META-INF/mods.toml；assets/monsterwaves/{lang,models,textures}。lang 文件为 CRLF 行尾。

掉落条目字段（normalLoot / eliteLoot / bossLoot 条目）

字段（GUI 英文）中文含义说明
item物品物品注册名，如 minecraft:diamond（任意模组物品）
nbtNBT附加 NBT 字符串（可空），如 {CustomTag:1}
minCount / maxCount数量掉落数量下限/上限（≥1，max≥min）
chance概率基础概率 0~1；最终 = chance × 难度 × 全局倍率（封顶 1）
isPlayerAffected受抢夺影响是否受 Looting 附魔加成
阶段掉落表（v1.0.7）：stageLoot 条目 = {stageId 阶段id(空=所有阶段), tier any/normal/elite/boss, entries 掉落条目}——匹配当前阶段+怪物等级后追加掉落，与三表叠加；elite 不含 Boss。
三表独立计算，不共享概率池：表间与表内条目均为独立 roll。Boss 掉落 = normalLoot + eliteLoot + bossLoot；精英 = normalLoot + eliteLoot；普通 = normalLoot。

7技能点系统

  • 获取：默认随等级（LEVEL），可 XP / DISABLED；SkillPointGainEvent 允许开发者完全接管获取算法
  • 白名单：attributeConfigs 决定可加点集合（默认 6 原版 + 4 枪械属性）；每属性独立配置 enabled / percentage / maxPoints / percentagePerPoint
  • 迁移：旧属性球数据一次性迁移（值/2→分配 + 总值 20% 补偿），skillMigrated 防重复
  • 技术坑（1.20.1）：AttributeMap 无 getAttributes/getAllAttributes（用 getSyncableAttributes()）；Button 6 参构造器不存在（用 Button.builder）
  • 键位：RegisterKeyMappingsEvent 必须在 mod 事件总线注册（Forge 总线回调不触发）

8精英 / Boss 系统

级别表现默认属性倍率经验
精英§c【精英】红名+发光（长期无粒子）生命 ×3 / 攻击 ×2 / 护甲 ×2×2
Boss§6【Boss】金名+发光+Boss 血条（ServerBossEvent 紫色条，全体可见）生命 ×50 / 攻击 ×10 / 护甲 ×10×20
  • 升级顺序：先判精英（eliteChance），中精英后在其基础上判 Boss（bossChance）；概率 ×√难度
  • 上限：maxElitesPerPlayer（默认 5）/ maxBossesPerPlayer（默认 1），-1=不限
  • 体型：配置 eliteScale（1.3）/ bossScale（2.0）；渲染缩放仅客户端，碰撞箱缩放仅服务端（1.20.1 反射 refreshDimensions）
  • 碰撞箱缩放目前失败：1.20.1 无可靠多体部件 API，`refreshDimensions` 客户端可能不同步——已知限制见 §12

9维度系统

休息维度（monsterwaves:safe，空岛）

  • 数据包注册（flat 全空），空岛代码生成（幂等，IslandData 标记）
  • 设施：中心十字 工作台/熔炉/箱子/高炉/烟熏炉/切石机 + 附魔台（5×5 外环 16 书架满级）
  • 玩家规则：不刷怪（MobSpawnEvent.PositionCheck DENY + 引擎跳过）、不饥饿（锁 20/10）、免疫伤害（LivingHurtEvent 取消）、跳下传送（Y<-10）
  • 跳下默认目标：战斗维度 arena 出生点（fallDestinationDimension，可配）；fallToRespawnPoint=true 时按维度出生点

战斗维度（monsterwaves:arena）

  • 超平坦 grass/dirt/stone 三层，出生点 (0,4,0)；原版自然生成被拦截，本模组引擎接管
  • 传送入口：/monsterwaves battle；坠落目标默认 arena

符咒（无限使用，无冷却）

物品作用合成（十字形：4 末影珍珠 + 中间）
return_charm 休息符咒传送休息维度金苹果
home_charm 回归符咒回主世界重生点指南针
battle_charm 战斗符咒传送战斗维度铁剑

10苦痛传递附魔（pain_transference）

  • 效果：命中怪物时对周围其他怪物造成「主伤害 × 30%~50%」传递伤害（无冷却）
  • 触发来源：近战（剑/斧/三叉戟，LivingHurtEvent）、弓/弩（ProjectileImpactEvent 原版箭）、TaCZ 枪械（GunPainTransferenceHandler 独立类，仅 tacz 加载时注册）
  • 创造栏「战斗用品」页含 1~5 级附魔书
  • 配置约束：半径/伤害百分比（每级递增）、affectSameTypeOnly、affectEliteBoss、excludeSource

11开发者 API（api 包，Forge 总线）

事件用途
SkillPointGainEvent技能点获取：可改数量 / 取消（自定义获取算法入口）
SkillPointSpentEvent加点消耗：可取消
SkillPointResetEvent重置：可取消
MobAttributeCalculateEvent怪物生命/攻击/护甲计算钩子：setCustomValue() + setCanceled(true) 完全接管算法。注意：Event.getResult() 是 final 方法，事件方法名为 setCustomValue/getCustomValue
// 示例：监听怪物属性计算（任何 mod 均可）
@SubscribeEvent
public static void onCalc(MobAttributeCalculateEvent e) {
    e.setCustomValue(e.getBaseValue() * (1 + e.getDifficulty() * 0.5)); // 自定义公式
    e.setCanceled(true);
}

12已知限制 / 调试要点

限制/坑说明
配置 GUI 子字段英文Cloth Config 11.1.136 对 List<POJO> 子字段（item/minCount 等）翻译键不生效——只能改 JSON，字段含义见 §3
碰撞箱缩放失败1.20.1 精英/Boss 体型缩放：渲染缩放（客户端）与碰撞箱缩放（服务端）不同步，碰撞箱缩放不可靠——属已知限制，不做
